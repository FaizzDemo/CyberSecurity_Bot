# Cybersecurity Fundamentals

## 1. Introduction to Cybersecurity

Cybersecurity is the practice of protecting computers, networks, applications, devices, and data from unauthorized access, damage, theft, and disruption.

### Why Cybersecurity Matters
- Protects personal and business information.
- Reduces financial loss and identity theft.
- Helps maintain reliable computer systems.
- Protects privacy and digital services.
- Supports business continuity and public safety.

## 2. The CIA Triad

The CIA triad describes three fundamental security goals.

### Confidentiality
Information should be accessible only to authorized people and systems.

Examples: access permissions, encryption, and multi-factor authentication.

### Integrity
Information should remain accurate and should not be modified without authorization.

Examples: file hashes, access controls, and change logs.

### Availability
Systems and data should be available when authorized users need them.

Examples: backups, redundancy, maintenance, and disaster recovery.

## 3. Important Security Terms

- Asset: Something valuable that requires protection.
- Threat: Something that could cause harm.
- Vulnerability: A weakness that could be exploited.
- Exploit: A method of taking advantage of a vulnerability.
- Risk: The potential for harm and its consequences.
- Attack surface: The points where a system could be exposed.
- Security control: A measure that reduces risk.
- Incident: An event that affects or may affect security.
- Patch: An update that fixes a bug or vulnerability.
- Malware: Software designed for harmful or unauthorized activity.

## 4. Authentication and Authorization

Authentication verifies an identity. Authorization determines what that identity is allowed to do.

Example: A student signs in using a password. The system authenticates the student and then checks whether the student can access a particular course.

Auditing records relevant activities so they can be reviewed later.

## 5. Common Cybersecurity Threats

### Phishing
Deceptive messages attempt to trick people into clicking malicious links, sharing credentials, or transferring money.

### Malware
Malicious software includes viruses, worms, trojans, spyware, and ransomware.

### Ransomware
Ransomware commonly encrypts files or threatens to disclose stolen information to demand payment.

### Social Engineering
An attacker manipulates a person into revealing information or taking an unsafe action.

### Denial of Service
A denial-of-service attack attempts to make a system unavailable by disrupting it or exhausting resources.

### Credential Theft
Passwords, authentication tokens, and other login secrets are obtained without authorization.

## 6. Essential Security Principles

### Least Privilege
Give users and applications only the permissions necessary for their tasks.

### Defense in Depth
Use multiple security layers, including MFA, firewalls, updates, monitoring, and backups.

### Secure by Default
Systems should use safe settings unless an authorized administrator changes them.

### Risk-Based Security
Prioritize security work based on likelihood, impact, exposure, and available protections.

## 7. Password and Account Security

- Use long, unique passwords.
- Use a reputable password manager.
- Enable multi-factor authentication.
- Never share one-time verification codes.
- Review account recovery options.
- Check for unfamiliar login sessions.
- Change exposed credentials from a trusted device.

## 8. Personal Device Security

1. Install security updates.
2. Use screen locks and device encryption.
3. Download software from trusted sources.
4. Back up important data.
5. Avoid unknown attachments and suspicious downloads.
6. Review application permissions.
7. Secure home Wi-Fi.
8. Remove applications you no longer need.

## 9. Understanding Risk

Risk assessment considers how likely an event is and how much harm it could cause.

A simple example is an outdated internet-facing server containing sensitive data. Its exposure, vulnerability, and potential impact make it a priority for investigation and remediation.

Risk ratings are estimates and must be interpreted in context.

## 10. Glossary

- MFA: Multi-factor authentication.
- IAM: Identity and Access Management.
- SOC: Security Operations Center.
- EDR: Endpoint Detection and Response.
- SIEM: Security Information and Event Management.
- IR: Incident Response.
- VPN: Virtual Private Network.
